# Thai–English Code-Switching ASR Research

Research snapshot: 2026-10-17. This note compares evidence for speech that changes between Thai and English within one sentence. “Transcription” means preserving what was spoken in its source language(s); “translation” means rendering speech into a selected target language. The claims below describe vendor documentation and published model materials, not an independent benchmark on this project's audio.

## Recommendation

For a user who needs Thai and English preserved in one transcript, Soniox is the only candidate reviewed with explicit first-party claims for mixed-language speech within a sentence and a Thai-specific mixed-language FAQ. That makes it the best-supported candidate to evaluate first, not a proven winner on this project's recordings. For a local path, compare the existing Whisper large-v3-compatible path against real reference clips; language coverage alone does not prove intra-sentence switching quality. Typhoon Whisper Large v3 is a Thai-recognition candidate, but the available card does not substantiate Thai–English switching. The Typhoon Real-Time model's own release note names this as a limitation.

Keep transcript and translation trials separate. For transcription, check whether English portions remain in English orthography while Thai portions remain Thai. For translation, specify the target language and score semantic fidelity separately from transcription fidelity. Include short embedded English words, technical names, and sustained switches, then inspect text as well as language tags. A single monolingual Thai/English score cannot answer the mixed-sentence question.

## Repository compatibility and evidence boundary

The current app's model-management contract explicitly accepts Whisper repositories and converts to CTranslate2 or OpenVINO. It validates Whisper architecture and uses the Transformers Whisper converter or Optimum OpenVINO Whisper wrapper. The Typhoon FastConformer/NeMo model needs a separate runtime adapter; Typhoon Whisper Large v3 is a candidate for the existing Whisper preparation path, with conversion and inference still requiring verification. Soniox and Scribe are hosted APIs, not local model weights, and would require a service adapter. No candidate has been tested here against the project's Thai–English reference audio.

The maintained user-facing [configuration guide](../../docs/configuration.md#model-configuration) already states that Auto detect delegates to the runtime and does not guarantee accurate recognition when languages change within a sentence. This research note is task evidence; it does not change that contract.
